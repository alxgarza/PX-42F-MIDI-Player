1. What it is

MIDI Player plays Standard MIDI Files (.mid) on the PX-42F's speaker. A MIDI file is a score, not a recording: it lists which notes each instrument plays and when. The calculator has a small synthesizer in its firmware that turns the score into sound, up to 24 notes at once on 16 channels, with drums on channel 10.

MIDI Player is an app: it starts from Settings → Games & Apps. It needs firmware with app API version 4 or later, the first that has the synthesizer.

2. Installing it

The app is one file, MIDI-Player.bin. It goes in the BIN/APPS folder on the calculator's drive.

  1. On the calculator, open Settings → USB Drive → Connect to Computer. A drive called PX-42F appears on the computer.
  2. Copy MIDI-Player.bin into BIN/APPS on that drive.
  3. Eject the drive. The calculator comes back to the menu.
  4. Open Settings → Games & Apps and choose MIDI-Player.

With the drive connected and the project open in VS Code, make install (the Install on the PX-42F task) does the copying.

3. Adding songs

The songs are the .mid files in the MIDI folder of the calculator's drive. The calculator makes the MIDI folder, with SONGS and SOUNDS inside it, the first time it starts after the update.

  • Your own songs. Connect the drive (Settings → USB Drive → Connect to Computer), copy .mid files into MIDI, eject. They show up in the list, sorted by name, without the .mid.
  • Names. At most 28 letters before the .mid; longer ones are left out. Folders inside SONGS aren't searched.
  • How many. The list holds 64 songs.
  • Which files. Standard MIDI Files of format 0 (one track) or 1 (several tracks), up to 128 KB. General MIDI files work best, because the instruments are picked by General MIDI program numbers (below).

4. The screen

From top to bottom:

Progress barHow far the song has got.

NotesThe number of notes sounding right now. It counts every note that still makes any sound, including ones that were just let go and are dying away, so it doesn't drop to 0 the instant the music stops. The synthesizer has 24 voices: if the number stays at 24, the song asks for more notes than it can play, and the oldest or quietest are cut.
The 16 boxesOne box for each MIDI channel, channel 1 at the left. A channel is one part of the song: the melody, the bass, the chords, the drums. A box is lit for the first three quarters of each note that plays on that channel, so a short note makes a short blink and a long note a long one, and stays empty when the channel is quiet. A very short note (a drum hit) still shows for a moment. The tenth box is channel 10, the drums. Use them to see which parts are playing.

5. The keys

KeyDoes
↑ ↓Choose a song (going past the end wraps around).

⌫ (backspace)Stop.
Σ+ (top left)Switch between Repeat (when a song ends, the next in the list plays, and after the last the first) and Once (play the song, then stop). The player starts in Repeat.

You can move through the list while a song plays; it keeps playing until you press ENTER on another one. The Sleep Timer ends the app, and the music, as it does for any app.

6. How it sounds

The calculator has no recorded instruments. Its synthesizer builds every note from simple waveforms, so it sounds like a good ringtone or an old computer, not like an orchestra. The speaker is small and has little bass.

Instruments

Each channel of a MIDI file chooses an instrument by a General MIDI program number (0–127). The synthesizer has eleven sounds and maps each program to the nearest:

ProgramsGeneral MIDI instrumentsPlays as
0–5PianosPiano: fast attack, fades while the key is held
6–7, 24–28, 45–46, 104–111Harpsichord, clavinet, acoustic and electric guitars, pizzicato, harp, sitar, banjo and other plucked onesPlucked
8–15, 112–119Celesta, glockenspiel, vibraphone, marimba, bells; steel drums, percussive instrumentsBell
16–23Organs, accordion, harmonicaOrgan: steady, no fade
32–39, 47Basses, timpaniBass
40–44, 48–51, 55Violin, viola, cello, string ensembles, orchestra hitStrings: slow attack, a little vibrato
56–63Trumpet, trombone, tuba, horns, brassBrass
64–71Saxophones, oboe, bassoon, clarinetReed
52–54, 72–79Choir and voices; piccolo, flute, recorder, pan flute, whistleFlute: soft, with vibrato
29–31, 80–87Overdriven and distortion guitars; square, saw and other synth leadsLead: bright, square-like
88–103, 120–127Synth pads and effects, sound effectsPad: slow and soft

Drums

Channel 10 is the drum kit, as in General MIDI, whatever its program. Each note number is one drum: bass drums (35, 36), snares (38, 40), toms (41–50), closed and open hi-hats (42, 44, 46), cymbals (49–59), cowbell, rim and clap; any other number gives a short click. A closed hi-hat cuts an open one short, as on a real kit.

What the player follows

  • Notes with their velocity (how hard they're struck), and tempo changes.
  • Volume, expression and modulation (vibrato), the sustain pedal, and pitch bend (up to two semitones).
  • “All notes off”, “all sound off” and “reset controllers”.
  • Everything else in the file (reverb, panning, lyrics, other controllers) is skipped. The speaker is a single one, so there is no stereo.

7. Tips

  • Loud songs. When many notes play at once, a limiter holds the loudness down, so a full band is not louder than one instrument, only fuller. Songs with fewer notes at once sound cleaner on this speaker.
  • Battery. The speaker draws more current than anything else in the calculator (up to about 200 mA in loud passages), and the processor runs at full speed while a song plays. Long listening on the battery empties it faster than normal use. Plug in the USB cable for long sessions.
  • Too many notes. If a song sounds thin, watch the notes number. If it sits at 24, the song uses more voices than the calculator has. Songs written for a few instruments (ringtones, game music, simple arrangements) fit best.
  • Where to find songs. Any .mid file works. If one sounds wrong, open it in a MIDI editor and check that each part uses a General MIDI program and the drums are on channel 10.
  • Hearing a song on the computer first. The PX-42F-Plus firmware project can render a song the way the calculator plays it into a WAV file, which you can listen to on the computer: tools/px_sound/run.sh OUT_DIR song.mid.

8. Messages

When a song can't be played, the line where the song's name would be says why, and nothing plays.

MessageMeans
Can't read the fileThe file isn't there any more, or the drive can't be read.
Not a MIDI file it can playThe file isn't a Standard MIDI File, or its header is damaged, or it has no music in it. (A .rmi file, which wraps the music in another format, is refused too.)
Too big (over 128 KB)The file is larger than the player accepts. Save it again with fewer tracks, or remove the parts you don't need.
Not enough memoryThe calculator's memory is too full to load the file. Quit the app, clear some memory (programs, variables) and try again.
No songs. Copy .mid files to /MIDI on the driveThe folder is empty. Add songs as in Adding songs.

A damaged file that does start never crashes the calculator: the player stops the part of the file that is broken and plays what is left.

9. What it doesn't do

  • No pause or fast-forward: you stop and start again from the beginning.
  • No recorded instruments (samples): every sound is made by the synthesizer.
  • No stereo, reverb or effects.
  • The file can't be larger than 128 KB, and the list shows 64 songs.
  • While a song plays, the app shouldn't save files: writing to the drive stops the synthesizer for a moment and the sound stutters.

10. For developers

The synthesizer lives in the PX-42F-Plus firmware (midiplay.c) and any app can use it with two functions of the app API (version 4). The player is a small example of it:

int midi_play(const char *path);          /* a .mid file; returns at once; 0 or PX_MIDI_* */
void midi_status(px_midi_status_t *st);   /* length_ms, elapsed_ms, channels (bit n = channel n+1), voices */

A song plays on the calculator's second processor, so the app goes on drawing; sound_playing() says when it's over and sound_stop() stops it. They are described in the PX-42F App Manual.
